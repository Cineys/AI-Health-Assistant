# 本地开发配置说明

本项目为微信小程序 + FastAPI 后端。克隆后需要做两处本地配置才能跑通。

---

## 1. 微信小程序 AppID

仓库中的 `project.config.json` 使用公开占位值：

```json
"appid": "touristappid"
```

`touristappid` 是微信开发者工具识别的「游客模式」占位 AppID，作用是不把项目作者的
小程序账号信息写进公开仓库。**它不能用于登录** —— 游客模式下 `wx.login` 拿不到可用于
换取 openid 的凭证，后端 `/api/login` 会失败。

### 填入自己的 AppID

**方式一（推荐，不会污染 Git 状态）**

用微信开发者工具打开本项目 → 右上角「详情」→「基本信息」→ 修改 AppID。
开发者工具会把个人配置写入 `project.private.config.json`，**不会**改动
`project.config.json`。本项目的 `.gitignore` 已排除该文件，因此你的 AppID 不会被提交。

**方式二**

直接编辑 `project.config.json` 的 `appid` 字段，填入自己的 AppID。
注意：这样修改会进入 Git 变更记录，提交前请确认不要推送自己的真实 AppID。

### 还需要配 AppSecret

后端 `backend-server/.env` 中的 `WECHAT_APPID` 与 `WECHAT_APP_SECRET` 必须与上一步的
AppID 属于同一个小程序账号，否则后端调用 `jscode2session` 会失败。
参考 `backend-server/.env.example`。

---

## 2. 后端 API 地址

前端所有请求地址统一在 **`utils/config.js`** 中配置，只需改这一个文件：

```js
const BASE_URL = 'http://127.0.0.1:8000'
```

`utils/api.js`、`utils/medication.js` 以及 `pages/chat`、`pages/emotional` 等页面
都从这个文件读取，不要在页面里另写地址。

### 模拟器 vs 真机

| 环境 | 该填什么 | 原因 |
|---|---|---|
| 微信开发者工具模拟器 | `http://127.0.0.1:8000`（默认值） | 请求由开发机发出，直达本机后端 |
| 真机预览 / 真机调试 | `http://<电脑局域网IP>:8000` | 手机上的 `127.0.0.1` 指向手机自己，必须用电脑的局域网 IP |

查询电脑局域网 IP：

```bash
# macOS
ipconfig getifaddr en0

# Windows
ipconfig          # 查看「IPv4 地址」
```

手机与电脑需连接**同一个 Wi-Fi / 局域网**。

### 微信开发者工具设置

开发阶段需勾选：

> 详情 → 本地设置 → **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

否则 `http://` 请求会被开发者工具拦截。

### 真机与线上限制

- 非 HTTPS 地址只有在**开发版 / 体验版**并**打开调试模式**时可用。
- 正式发布必须使用 HTTPS，并在微信公众平台配置 `request` 合法域名。

### 启动后端

后端默认监听 8000 端口：

```bash
cd backend-server
uvicorn app:app --host 0.0.0.0 --port 8000
```

注意使用 `--host 0.0.0.0`（而不是 `127.0.0.1`），否则真机无法访问。

启动前请先按 `backend-server/.env.example` 创建 `backend-server/.env`，
并参考 README 构建向量库。
